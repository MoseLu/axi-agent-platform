                              (e.g. --only-decide=cancelled)

Per-task decision table (decisionFor function):
  - cwd present + VERIFICATION.md present + stored passed → keep-completed
  - cwd missing → cancelled (target retired; NOT a failure)
  - history has 'failed' → failed
  - else → awaiting_audit

--apply safety:
  - writes backup snapshot to <home>/.m1-snapshot/m5-audit/pre-apply-<ISO>.json
    BEFORE any mutation
  - for keep-completed: appends 'm5_recheck_kept' history entry, does NOT
    change status
  - for cancelled / failed / awaiting_audit: flips status and appends
    'm5_recheck_<decision>' history entry
