## Commit Body

M2 unconditionally probed both stores on every boot, paying a PG connect on every JSON-only daemon/MCP-server boot and a JSON file read on every PG-only boot. M4 inverts this default: when the caller has declared a chosen side (via AXI_TODO_STORE or via auto resolution picking one store), trust that decision and skip the cross-store probe.

Behavior:
- AXI_TODO_DUAL_PROBE unset: returns { warned: false, chosen, reason: 'probe-skipped' } immediately after the chosen-side classification — no cross-store IO.
- AXI_TODO_DUAL_PROBE=1: full M2 behavior preserved (probe both sides, emit warning if both populated).
- AXI_TODO_DUAL_PROBE=<anything-else>: same as unset (string compare to '1').

Three boot callers (bin/axi-todo.mjs:12 / bin/axi-todo-daemon.mjs:8 / lib/mcp-server.mjs:6) are unchanged — they pass { store } only and the gating is internal to warnIfDualPopulated. No caller surface change.
