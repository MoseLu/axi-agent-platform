## Commit Body

Reentrant PG→JSON importer for the canonical JSON ledger. Swift desktop
is structurally bound to `~/.axi-todo/tasks.json`, so JSON is canonical
and PG is opt-in. The importer is the only sanctioned path for PG rows
to enter JSON.

- Reads `payload` jsonb from `axi_todo.tasks` and feeds it through
  `createTask()` after splicing `source: "import-postgres"` and
  `importedAt` provenance fields.
- Tracks imported ids in `$AXI_TODO_HOME/.imported-pg-ids.json` so
  re-runs are idempotent; ids that already exist in `tasks.json` are
  skipped (existing JSON wins).
- Supports `--dry-run` for safe previews; exits 1 on missing env vars
  (no silent `postgresql:///axi_todo` fallback), 2 on write failure.
- Schema extended with `source` + `importedAt` so future re-importers
  can mark provenance too.
- `bin/axi-todo-import-postgres.mjs` only runs `main()` when invoked
  directly, so tests can import the orchestrator (`runImport`) cleanly.
- M2 ledger committed at `.m1-snapshot/ledger/m2-entries.json` with
  `outOfScopeButFlagged` (3 latent PG bugs) and `ownerDecisionsRequired`
  (default flip + PG retention).
