## Commit Body

M6 parity: the lib/postgres-store.mjs PG-side create*Record helpers (commit 2db9786) already inherit source / importedAt from the parent task. This commit mirrors the same normalization onto lib/store.mjs so JSON-side records — created by store.completeTask / store.failTask — carry the same provenance. Without it, an imported task's JSON-side completion summary / failure analysis / memory card would record source='native' and lose the trail.

Also fixes a silent regression in searchPlanningMemory introduced by adding source / importedAt to per-record shapes: { source: "planning_records", ...item } previously spread the record LAST, so an item with source='native' or source='import-postgres' overwrote the collection-name marker that searchCollectionText keys on, breaking the search for every collection. Reordered to { ...item, source: "<collection>" } so the collection marker always wins. searchCollectionText then routes to the right MEMORY_SEARCH_FIELDS entry.
