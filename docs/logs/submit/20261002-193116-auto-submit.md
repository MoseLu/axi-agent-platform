## Commit Body

M7 mirrors the M4 / M6 sticky source / imported_at provenance pattern onto
the two runtime event tables: audit_reviews and task_events. Both methods
already had inline INSERTs in lib/postgres-store.mjs; this commit adds
source + imported_at columns to the column list and an ON CONFLICT (id)
DO UPDATE clause that deliberately omits both columns so re-upserts
preserve the original import marker. The payload jsonb column is reverse-
synced from the canonical source / imported_at column values on every
conflict so JSON-side readers (Swift AxiTodoStore, Kibana search index,
bin/axi-todo-import-postgres.mjs re-runs) keep seeing source / importedAt
without code changes — same shape as the M4 tasks and M6 four collections.

recordTaskEvent: previously a single INSERT (no ON CONFLICT). Now INSERT
.. ON CONFLICT (id) DO UPDATE with sticky SET list (omits source /
imported_at, reverse-syncs payload). Defaults cover the only call site that
omits source (recordTaskEvent consumers in lib/store.mjs) and lib/daemon.mjs
by reading record.source ?? 'native' and record.importedAt ?? null.

recordAuditReview: M3.S4 (commit 150fac5) wrapped audit_reviews INSERT +
status flip + audit_waiting task_events INSERT in a single withClient
transaction. This commit preserves that transaction shape end-to-end
(verified structurally by the new migrate-event-provenance.test.mjs):
audit_reviews INSERT now binds source + imported_at with sticky ON
CONFLICT, the status-flip upsertTask call still routes through the
existing M3.S4 path unchanged, and the audit_waiting task_events INSERT
that fires on non-pass verdicts now binds the same source + imported_at
so the audit + history trail stays tied to a single origin marker even
on rollback. The withClient wrapper commits/rollback untouched — the
audit + status + event trio still rolls back together or commits
together.

No changes to the M3.S4 transaction semantics: BEGIN / audit_reviews
INSERT / getTaskForUpdate / status flip upsertTask / audit_waiting
task_events INSERT / COMMIT all on the same client.
